# setCredentialProvider

Swap in a [credential provider](/docs/guides/identity) after construction.

Useful when the wallet a user authenticates with is not known at the time you build the
instance — a browser app, typically, where `Nautilus.create` runs before the user connects.

## Usage

```ts twoslash
import { Nautilus, StaticCredentialProvider } from '@deltadao/nautilus'
import { Wallet } from 'ethers'
const nautilus = await Nautilus.create(new Wallet('0x1234'))
// ---cut---
nautilus.setCredentialProvider(new StaticCredentialProvider('a-session-id')) // [!code focus]
```

## Returns

- Type: `void`

## Parameters

### credentials

- Type: `CredentialProvider`

Any implementation of the interface — `WaltIdCredentialProvider` for a real wallet,
`StaticCredentialProvider` when you already hold a verifier session id, or
`NoopCredentialProvider` to disable SSI again.
