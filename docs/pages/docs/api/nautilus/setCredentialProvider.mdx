# setCredentialProvider

Swap in a [credential provider](/docs/guides/identity) after construction, or remove it with
`undefined`.

Useful when the wallet a user authenticates with is not known at the time you build the
instance — a browser app, typically, where `Nautilus.create` runs before the user connects.

## Usage

```ts twoslash
import { Nautilus, WaltIdCredentialProvider } from '@deltadao/nautilus'
import { Wallet } from 'ethers'
const nautilus = await Nautilus.create(new Wallet('0x1234'))
// ---cut---
nautilus.setCredentialProvider( // [!code focus]
  new WaltIdCredentialProvider(nautilus.getNodeClient(), { // [!code focus]
    walletApi: 'https://wallet.example.org' // [!code focus]
  }) // [!code focus]
) // [!code focus]
```

Sessions already verified stay cached.

## Returns

- Type: `void`

## Parameters

### credentials

- Type: `CredentialProvider | undefined`

Any implementation of the interface, e.g. `WaltIdCredentialProvider` for a walt.id wallet.
It is asked only for services whose `SSIpolicy` asks for credentials: nautilus opens the
policy-server session of an address-gated service without one. `undefined` removes the
provider: a service that asks for a presentation is then refused before anything is spent.
