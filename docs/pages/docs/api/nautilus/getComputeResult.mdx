# getComputeResult

Get a download URL for a finished job's result: by default its `output`, `outputs.tar`.

## Usage

```ts twoslash
import { Nautilus } from '@deltadao/nautilus'
import { Wallet } from 'ethers'
const nautilus = await Nautilus.create(new Wallet('0x1234'))
// ---cut---
const url = await nautilus.getComputeResult({ jobId: 'a-job-id' }) // [!code focus]

if (url) {
  const results = await fetch(url)
}
```

## Returns

- Type: `string | undefined`

`undefined` — with a log line explaining which — when the node does not know the job, the
job has not reached a terminal status, or it has no `output` result and no
`resultIndex` was given.

Both `70` (`JobFinished`) and `71` (`JobSettle`) count as terminal: by the time a job
reaches `71` the algorithm has run and its outputs are listed, and only the
payment-claim cron is outstanding. There is no need to wait through `71`.

The `output` result is `outputs.tar`, a **tar archive** of what the algorithm wrote to its
outputs folder. It is listed only when the results stay on the node, not when the job was
started with `output` storage or an `outputBucketId`.

To stream a large result instead of downloading it through a URL, use
[`streamComputeResult`](/docs/api/nautilus/streamComputeResult).

## Parameters

### config

- Type: `ComputeResultConfig`

#### Properties

##### jobId

- Type: `string`

`<environmentHash>-<jobId>`, as [`compute`](/docs/api/nautilus/compute) returns it.

##### resultIndex (optional)

- Type: `number`

The `index` of the result to fetch, from the job's `results`. Defaults to its `output`
result. On ocean-node 4.2 a finished job lists `imageLog` (`image.log`),
`configurationLog` (`configuration.log`), `algorithmLog` (`algorithm.log`) and `output`
(`outputs.tar`), in that order, and `publishLog` (`publish.log`) when the node wrote one.

##### nodeUri (optional)

- Type: `string`
