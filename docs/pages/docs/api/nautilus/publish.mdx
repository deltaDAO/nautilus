# publish

Publish a new asset.

## Usage

```ts twoslash
import { JsonRpcProvider, Wallet } from 'ethers'
import {
  AssetBuilder,
  FileTypes,
  Nautilus,
  NodePersistentRemoteStore,
  ServiceBuilder,
  ServiceTypes
} from '@deltadao/nautilus'

const signer = new Wallet('0x1234', new JsonRpcProvider('https://rpc.dev.pontus-x.eu'))
const config = { oceanNodeUri: 'https://node.example.org' }

const bootstrap = await Nautilus.create(signer, { config })
const nautilus = await Nautilus.create(signer, {
  config,
  remoteStore: new NodePersistentRemoteStore(bootstrap.getNodeClient())
})

const service = new ServiceBuilder<ServiceTypes.ACCESS, FileTypes.URL>({
  serviceType: ServiceTypes.ACCESS
})
  .setServiceEndpoint('https://node.example.org')
  .setName('Access Service')
  .setTimeout(86400)
  .addFile({ type: 'url', url: 'https://data.example/set.csv', method: 'GET' })
  .setPricing({ type: 'free' })
  .build()

const asset = new AssetBuilder()
  .setType('dataset')
  .setName('My Dataset')
  .setDescription('What it contains')
  .setProvidedBy('My Organisation')
  .addService(service)
  .build()

const { ddo, nftAddress } = await nautilus.publish(asset) // [!code focus]
```

What happens in order:

1. Trusted algorithms are resolved to their container and file checksums. This hits the
   network and can fail, so it happens before any NFT exists.
2. The NFT, the first service's datatoken and that service's pricing are created in **one**
   transaction. Each further service gets its own datatoken on the same NFT.
3. Each service's file object is encrypted by the node.
4. The DDO is built and **validated locally** against the DDO v5 SHACL schema. A missing
   field fails here, before any metadata transaction — no gas wasted.
5. The DDO is signed as a verifiable credential and stored in the remote store.
6. The `{ remote }` pointer is encrypted and written onto the NFT.

:::warning
Publishing requires a `remoteStore` on the instance — nautilus writes a pointer to the
signed DDO, not the DDO itself. See [`create`](/docs/api/nautilus/create#remotestore).
:::

## Returns

- Type: [`PublishResponse`](/docs/api/PublishResponse)

## Parameters

### asset

- Type: `NautilusAsset`

Built with the [`AssetBuilder`](/docs/api/AssetBuilder).

### options (optional)

- Type: `PublishOptions`

#### Properties

##### waitForIndexer

- Type: `boolean`

Block until ocean-node's indexer has the asset, so the result is immediately resolvable.
Sets `indexed` on the response.

```ts twoslash
import { Nautilus, type NautilusAsset } from '@deltadao/nautilus'
import { Wallet } from 'ethers'
const nautilus = await Nautilus.create(new Wallet('0x1234'))
const asset = {} as NautilusAsset
// ---cut---
const { indexed } = await nautilus.publish(asset, { waitForIndexer: true }) // [!code focus]
```

##### encrypt

- Type: `boolean`
- Default: `true`

Encrypt the on-chain pointer (metadata flags `0x02`). Set `false` to write it in plaintext
hex (flags `0x00`), which makes the pointer readable directly from chain.

##### remoteStore / ddoSigner

Override the instance's remote store or DDO signer for this call.
