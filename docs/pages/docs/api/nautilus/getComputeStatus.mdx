# getComputeStatus

Get the status of a compute job.

## Usage

```ts twoslash
import { Nautilus } from '@deltadao/nautilus'
import { Wallet } from 'ethers'
const nautilus = await Nautilus.create(new Wallet('0x1234'))
// ---cut---
const job = await nautilus.getComputeStatus({ jobId: 'a-job-id' }) // [!code focus]

console.log(job?.status, job?.statusText)
```

:::info
v1 required a `providerUri`. It now defaults to the node the instance is configured with;
pass `nodeUri` only for a job running on a different node.
:::

## Returns

- Type: `NodeComputeJob | undefined`

The job, under the `jobId` you passed, with the node's `environment`, `resources` and
`payment` beside the `ComputeJob` fields. `undefined` when the node does not know the job;
it is never another job of yours. Status `70` (`JobFinished`) and `71`
(`JobSettle`) both mean the results are ready — either is enough for
[`getComputeResult`](/docs/api/nautilus/getComputeResult) to return a URL.

## Parameters

### config

- Type: `ComputeStatusConfig`

#### Properties

##### jobId

- Type: `string`

`<environmentHash>-<jobId>`, as [`compute`](/docs/api/nautilus/compute) and
[`freeCompute`](/docs/api/nautilus/freeCompute) return it. A bare id throws: asked for one,
ocean-node lists every job of the consumer instead of filtering. To rebuild the full id
from a bare one, put the first segment of the job's environment id and a dash in front of
it.

##### nodeUri (optional)

- Type: `string`

For a job on another node.

##### agreementId (optional)

- Type: `string`
