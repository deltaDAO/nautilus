# stopCompute

Stop a running compute job.

## Usage

```ts twoslash
import { Nautilus } from '@deltadao/nautilus'
import { Wallet } from 'ethers'
const nautilus = await Nautilus.create(new Wallet('0x1234'))
// ---cut---
const jobs = await nautilus.stopCompute({ jobId: 'a-job-id' }) // [!code focus]
```

:::info
v1 required a `did` and a `providerUri`. The node identifies a job by id alone; `did` is
still accepted for symmetry but ignored, and the node defaults to the configured one.
:::

## Returns

- Type: `ComputeJob[]`

The jobs as they stand after the stop request.

## Parameters

### config

- Type: `StopComputeConfig`

##### jobId

- Type: `string`

- Type: `string`

##### agreementId (optional)

- Type: `string`

##### did (optional)

- Type: `string`
