# build

Builds the `NautilusAsset` that was configured using this builder instance.

## Usage

```ts twoslash
import { AssetBuilder } from '@deltadao/nautilus'

const assetBuilder = new AssetBuilder()

assetBuilder.setName('Test') // [!code focus]
assetBuilder.setDescription('My description') // [!code focus]
assetBuilder.build() // [!code focus]
// @log: ddo.metadata: 
// @log: { 
// @log:    name: 'Test',
// @log:    description: 'My description'
// @log: }
```

## Checks

`build()` throws for a new asset without `name`, `type`, `providedBy` or a service. It also
checks the SSI policies of the asset and its services, see
[`setSsiPolicyLint`](/docs/api/assetbuilder/setSsiPolicyLint): it logs a warning for
`holder-binding`, for `presentation-definition` with `jwt_vc_json` credentials and for request
credentials without per-credential issuer trust, and throws an `SsiPolicyError` for policies
the policy server would weaken or walt.id would fail on every presentation (a VC policy with
arguments at asset or service level, a bare `minimum-credentials`).

## Returns

- `NautilusAsset`

The built asset with all data that was set using the builder functions.
This can then be used in [`publish()`](/docs/api/nautilus/publish) or [`edit()`](/docs/api/nautilus/edit) calls respectively.
