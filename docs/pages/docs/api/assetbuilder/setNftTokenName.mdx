# setNftTokenName

Set the name of the NFT.

The default token name is `Nautilus Dataservice NFT`.

:::warning[Publish only]
An edit cannot change the NFT, which exists already. On an `AssetBuilder` constructed from a resolved asset (an edit builder), `setNftTokenName()` throws. Earlier releases ignored it there, silently. See [What an edit cannot change](/docs/guides/edit#what-an-edit-cannot-change).
:::

## Usage

```ts twoslash
import { AssetBuilder, Nautilus } from '@deltadao/nautilus'
import { Wallet } from 'ethers'

const nautilus = await Nautilus.create(new Wallet('0x1234'))

const assetBuilder = new AssetBuilder()
assetBuilder.setNftTokenName('NFT name') // [!code focus]
const asset = assetBuilder.build() // [!code focus]

await nautilus.publish(asset) // [!code focus]
```

## Returns

- Type: [`AssetBuilder`](/docs/api/AssetBuilder)

The asset builder instance, to chain further calls with.

## Parameters

### name

- Type: `string`

A short descriptive name to use for the NFT.

```ts twoslash
import { AssetBuilder } from '@deltadao/nautilus'

const assetBuilder = new AssetBuilder()
// ---cut---
assetBuilder.setNftTokenName(
    'NFT name' // [!code focus]
)
```
