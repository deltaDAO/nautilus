# setLicense

Set the license for the asset.

## Usage

```ts twoslash
import { AssetBuilder, Nautilus } from '@deltadao/nautilus'
import { Wallet } from 'ethers'

const nautilus = await Nautilus.create(new Wallet('0x1234'))

const assetBuilder = new AssetBuilder()
assetBuilder.setLicense('Apache-2.0') // [!code focus]
const asset = assetBuilder.build() // [!code focus]

await nautilus.publish(asset) // [!code focus]
// @log: ddo.metadata: 
// @log: { 
// @log:    license: { name: 'Apache-2.0' }
// @log: }
```

:::warning[Shape changed in DDO v5]
v5 stores the license as a structured object. A bare string is wrapped into `{ name }` for
you, so v1-style calls keep working — pass the object form when you need ODRL terms.
:::

## Returns

- Type: [`AssetBuilder`](/docs/api/AssetBuilder)

The asset builder instance, to chain further calls with.

## Parameters

### license

- Type: `string | License`

A public-domain declaration, an [SPDX identifier](https://spdx.org/licenses/), a URL, or a
full `License` object for ODRL terms.

```ts twoslash
import { AssetBuilder } from '@deltadao/nautilus'

const assetBuilder = new AssetBuilder()
// ---cut---
assetBuilder.setLicense(
    'https://link.to/my/custom-license' // [!code focus]
)
```
