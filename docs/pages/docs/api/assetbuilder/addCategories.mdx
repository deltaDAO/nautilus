# addCategories

Add any additional information you might need to describe your asset.

## Usage

```ts twoslash
import { AssetBuilder } from '@deltadao/nautilus'

const assetBuilder = new AssetBuilder()
// ---cut---
assetBuilder.addCategories(['weather', 'timeseries']) // [!code focus]
```

Categories are deduplicated, and repeated calls accumulate rather than replace.

:::tip
Prefer [`addTags()`](/docs/api/assetbuilder/addTags) where you can — tags have broader
adoption throughout the stack, and most portals surface them rather than categories.
:::

## Returns

- Type: [`AssetBuilder`](/docs/api/AssetBuilder)

The asset builder instance, to chain further calls with.

## Parameters

### categories

- Type: `string[]`

The categories you want to add to the asset to be built.
