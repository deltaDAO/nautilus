# addAdditionalInformation

Attach arbitrary extra information to the asset's metadata.

Merged rather than replaced, so repeated calls accumulate.

## Usage

```ts twoslash
import { AssetBuilder } from '@deltadao/nautilus'

const assetBuilder = new AssetBuilder()
// ---cut---
assetBuilder.addAdditionalInformation({ // [!code focus]
  updateFrequency: 'hourly', // [!code focus]
  rowCount: 8760, // [!code focus]
  termsAccepted: true // [!code focus]
}) // [!code focus]
```

:::warning
DDO v5 narrowed this to primitive values — `string`, `number` or `boolean`. In v4 it accepted
`any`, so nested objects went in directly. They now have to be serialised by the caller:

```ts twoslash
import { AssetBuilder } from '@deltadao/nautilus'
const assetBuilder = new AssetBuilder()
// ---cut---
assetBuilder.addAdditionalInformation({
  termsAndConditions: JSON.stringify({ // [!code focus]
    hash: '0xabc...', // [!code focus]
    signature: '0xdef...' // [!code focus]
  }) // [!code focus]
})
```

Note also that this field is indexed with `enabled: false` by ocean-node, so it is stored and
returned but **not searchable**. Anything you need to query on belongs in a field of its own.
:::

## Returns

- Type: [`AssetBuilder`](/docs/api/AssetBuilder)

The asset builder instance, to chain further calls with.

## Parameters

### additionalInformation

- Type: `Record<string, string | number | boolean>`
