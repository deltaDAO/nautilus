# addCredentialAccessList

Gate the asset on membership of an on-chain access list.

New in DDO v5. The access list is an ERC721-style contract; anyone holding a token from it satisfies the rule. Useful when membership already exists on chain and you do not want a verifiable-credential exchange.

## Usage

```ts twoslash
import { AssetBuilder } from '@deltadao/nautilus'

const assetBuilder = new AssetBuilder()
// ---cut---
import { CredentialListTypes } from '@deltadao/nautilus'

assetBuilder.addCredentialAccessList(CredentialListTypes.ALLOW, { // [!code focus]
  chainId: 32456, // [!code focus]
  accessList: '0xAccessListContractAddress' // [!code focus]
}) // [!code focus]
```

## Returns

- Type: [`AssetBuilder`](/docs/api/AssetBuilder)

The asset builder instance, to chain further calls with.
