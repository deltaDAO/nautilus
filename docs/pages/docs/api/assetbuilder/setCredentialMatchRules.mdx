# setCredentialMatchRules

Control how multiple credential rules combine.

The policy server's defaults are `match_allow: 'all'` (every allow rule must match) and `match_deny: 'any'` (any deny rule blocks).

## Usage

```ts twoslash
import { AssetBuilder } from '@deltadao/nautilus'

const assetBuilder = new AssetBuilder()
// ---cut---
assetBuilder.setCredentialMatchRules({ // [!code focus]
  match_allow: 'any', // [!code focus]
  match_deny: 'any' // [!code focus]
}) // [!code focus]
```

## Returns

- Type: [`AssetBuilder`](/docs/api/AssetBuilder)

The asset builder instance, to chain further calls with.
