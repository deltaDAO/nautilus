# setNftTokenUri

Image link associated with the asset. Will be saved in the base64 encoded NFT metadata (`data:application/json;base64`). 

The default token uri is an empty string(`''`). 

:::warning[Publish only]
An edit cannot change the NFT, which exists already. On an `AssetBuilder` constructed from a resolved asset (an edit builder), `setNftTokenUri()` throws. Earlier releases ignored it there, silently. See [What an edit cannot change](/docs/guides/edit#what-an-edit-cannot-change).
:::

## Usage

```ts twoslash
import { AssetBuilder, Nautilus } from '@deltadao/nautilus'
import { Wallet } from 'ethers'

const nautilus = await Nautilus.create(new Wallet('0x1234'))

const assetBuilder = new AssetBuilder()
assetBuilder.setNftTokenUri('https://www.example.com/images/logo.png') // [!code focus]
const asset = assetBuilder.build() // [!code focus]

await nautilus.publish(asset) // [!code focus]
```

## Returns

- Type: [`AssetBuilder`](/docs/api/AssetBuilder)

The asset builder instance, to chain further calls with.

## Parameters

### uri

- Type: `string`

A link to your asset image.

```ts twoslash
import { AssetBuilder } from '@deltadao/nautilus'

const assetBuilder = new AssetBuilder()
// ---cut---
assetBuilder.setNftTokenUri(
    'https://www.example.com/images/logo.png' // [!code focus]
)
```
