# createAuthToken

Mint a node session token, so subsequent calls skip the nonce-and-sign round trip.

## Usage

```ts twoslash
import { createAuthToken, revokeAuthToken } from '@deltadao/nautilus'
import type { Signer } from 'ethers'

declare const signer: Signer
const nodeUri = 'https://ocean-node.dev.pontus-x.eu'
// ---cut---
const token = await createAuthToken(signer, nodeUri) // [!code focus]

// … many calls later
await revokeAuthToken(signer, token, nodeUri) // [!code focus]
```

:::info
A client authenticating with a token reads the consumer address from the token's `address`
claim, as ocean.js does. Give it `consumerAddress` only for a token without that claim.
:::

## Returns

- Type: `Promise<string>`

The bearer token.

### signer

- Type: `Signer`

### nodeUri

- Type: `string`
