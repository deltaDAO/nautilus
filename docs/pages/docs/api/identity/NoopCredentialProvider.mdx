# NoopCredentialProvider

Resolves to `null` for every challenge — no credentials, ever.

## Usage

```ts twoslash
import { NoopCredentialProvider } from '@deltadao/nautilus'
// ---cut---
const credentials = new NoopCredentialProvider() // [!code focus]
```

This is the default when you pass no `credentials`, so you rarely construct it yourself. It
is useful to **disable** SSI again after
[`setCredentialProvider`](/docs/api/nautilus/setCredentialProvider) installed a real one.

:::info
A gated asset will then simply fail to resolve its policy. To skip the exchange for one call
instead, pass `skipCredentials: true` to
[`access`](/docs/api/nautilus/access).
:::
