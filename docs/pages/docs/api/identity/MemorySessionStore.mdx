# MemorySessionStore

The default cache for verifier sessions, held in process.

## Usage

```ts twoslash
import { MemorySessionStore, WaltIdCredentialProvider } from '@deltadao/nautilus'
import type { OceanNodeClient } from '@deltadao/nautilus'

declare const node: OceanNodeClient
// ---cut---
const credentials = new WaltIdCredentialProvider(node, {
  walletApi: 'https://wallet.example.org',
  sessionStore: new MemorySessionStore() // [!code focus]
})
```

Sessions are keyed by `{ nodeUri, did, serviceId, consumerAddress }`, so re-accessing the
same gated service does not repeat the exchange — while switching accounts, or reaching a
service hosted on another node, does. A session id means nothing to a policy server that
did not mint it.

:::info
Implement `SessionStore` yourself — `get`, `set`, `delete`, `clear` — to share sessions across
processes or persist them between runs.
:::

See [credential-gated assets](/docs/guides/identity).
