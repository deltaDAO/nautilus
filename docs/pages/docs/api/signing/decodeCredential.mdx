# decodeCredential

Read a credential's payload without verifying its signature.

## Usage

```ts twoslash
import { decodeCredential } from '@deltadao/nautilus'

declare const jwt: string
// ---cut---
const payload = decodeCredential(jwt) // [!code focus]

payload.id // the DID
payload.issuer
```

:::warning
This decodes; it does not verify. Do not use it to decide whether a credential is
trustworthy.
:::

## Returns

- Type: `Record<string, unknown>`

The decoded JWT payload — the DDO plus the credential envelope.

## Parameters

### jwt

- Type: `string`

A compact JWT, such as the one on
[`PublishResponse`](/docs/api/PublishResponse)'s `credential`.
