# getOwner

The NFT owner the node reports for the asset.

:::warning
ocean-node reports here the account that wrote the metadata **last**, not the NFT's owner:
after a manager-role account edits the asset it names the manager, after an NFT transfer it
names the old owner until the next edit, and a malicious node can name anyone. Do not use it
to decide who administers the asset or receives its revenue: read `ownerOf` on the NFT
contract (the chain is the authority). `edit()` does so itself.
:::

## Usage

```ts twoslash
import { Nautilus, getOwner } from '@deltadao/nautilus'
import { Wallet } from 'ethers'
const nautilus = await Nautilus.create(new Wallet('0x1234'))
// ---cut---
const asset = await nautilus.getAsset('did:ope:1234abcd...')

const owner = getOwner(asset) // [!code focus]
```

## Returns

- Type: `string | undefined`

Read from indexer-derived data, so it is `undefined` on a document the indexer has not
processed yet — for example one you just built locally.
