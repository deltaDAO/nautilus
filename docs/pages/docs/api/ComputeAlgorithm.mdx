# ComputeAlgorithmRef

References the algorithm to run, in
[`nautilus.compute()`](/docs/api/nautilus/compute) and
[`nautilus.freeCompute()`](/docs/api/nautilus/freeCompute).

Everything [`ComputeAssetRef`](/docs/api/ComputeAsset) has, plus two algorithm-specific
fields.

:::warning
Renamed from `ComputeAlgorithm` in v1, for the same reason as `ComputeAssetRef`: ocean.js
exports a different type under that name.
:::

## Usage

```ts twoslash
import type { ComputeAlgorithmRef } from '@deltadao/nautilus'
// ---cut---
const algorithm: ComputeAlgorithmRef = {
  did: 'did:ope:5678wxyz...'
}
```

## Properties

### did / serviceId / userdata

As [`ComputeAssetRef`](/docs/api/ComputeAsset).

### algocustomdata (optional)

- Type: `Record<string, unknown>`

Values for the *algorithm's* own consumer parameters, declared in its algorithm metadata
(`metadata.algorithm.consumerParameters`), as distinct from the `userdata` its service
takes. Checked before anything is sent (see
[validation](/docs/api/UserCustomParameters#validation)).

```ts twoslash
import type { ComputeAlgorithmRef } from '@deltadao/nautilus'
// ---cut---
const algorithm: ComputeAlgorithmRef = {
  did: 'did:ope:5678wxyz...',
  algocustomdata: { epochs: 10 } // [!code focus]
}
```

### envs (optional)

- Type: `Record<string, string>`

Environment variables set inside the algorithm container. New in C2D v2.

```ts twoslash
import type { ComputeAlgorithmRef } from '@deltadao/nautilus'
// ---cut---
const algorithm: ComputeAlgorithmRef = {
  did: 'did:ope:5678wxyz...',
  envs: { LOG_LEVEL: 'debug' } // [!code focus]
}
```
