# removeTrustedAlgorithmPublisher

Stop trusting a publisher.

Matched case-insensitively, so a checksummed and a lower-cased address are the same entry.

## Usage

```ts twoslash
import {
  FileTypes,
  ServiceBuilder,
  ServiceTypes
} from '@deltadao/nautilus'

const serviceBuilder = new ServiceBuilder<ServiceTypes.COMPUTE, FileTypes.URL>({
  serviceType: ServiceTypes.COMPUTE
})
// ---cut---
serviceBuilder.removeTrustedAlgorithmPublisher('0x0db823218e337a6817e6d7740eb17635deadafaf') // [!code focus]
```

## Returns

- Type: [`ServiceBuilder`](/docs/api/ServiceBuilder)

The service builder instance, to chain further calls with.
