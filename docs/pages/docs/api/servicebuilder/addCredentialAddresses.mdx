# addCredentialAddresses

Restrict this service to specific addresses.

New in DDO v5: gating is per-service as well as per-asset, so one service of an asset can be restricted while another is open.

## Usage

```ts twoslash
import {
  FileTypes,
  ServiceBuilder,
  ServiceTypes
} from '@deltadao/nautilus'

const serviceBuilder = new ServiceBuilder<ServiceTypes.ACCESS, FileTypes.URL>({
  serviceType: ServiceTypes.ACCESS
})
// ---cut---
import { CredentialListTypes } from '@deltadao/nautilus'

serviceBuilder.addCredentialAddresses(CredentialListTypes.ALLOW, [ // [!code focus]
  '0x0DB823218e337a6817e6D7740eb17635DEAdafAF' // [!code focus]
]) // [!code focus]
```

:::warning
Asset-level and service-level address lists interact. When a service defines its own list,
the policy server requires **both** the asset's and the service's rules to match. Where the
service defines none, only the asset's list applies.
:::

## Returns

- Type: [`ServiceBuilder`](/docs/api/ServiceBuilder)

The service builder instance, to chain further calls with.
