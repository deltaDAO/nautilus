# setDatatokenNameAndSymbol

Name the datatoken minted for this service.

Defaults to a generated name. Worth setting when an asset has several services, so they are distinguishable on chain.

:::warning[New services only]
A published service's datatoken exists already, and an edit does not change it. On a `ServiceBuilder` loaded with a published service (`{ asset, serviceId }`), `setDatatokenNameAndSymbol()` throws (earlier releases ignored it there, silently). It stays valid on a new service, including one an edit adds to a published asset: `edit()` creates that service's datatoken with these parameters.
:::

## Usage

```ts twoslash
import {
  FileTypes,
  ServiceBuilder,
  ServiceTypes
} from '@deltadao/nautilus'

const serviceBuilder = new ServiceBuilder<ServiceTypes.ACCESS, FileTypes.URL>({
  serviceType: ServiceTypes.ACCESS
})
// ---cut---
serviceBuilder.setDatatokenNameAndSymbol('Observations Access', 'OBS-AT') // [!code focus]
```

## Returns

- Type: [`ServiceBuilder`](/docs/api/ServiceBuilder)

The service builder instance, to chain further calls with.
