# ComputeAssetRef

References a published dataset to compute on, in
[`nautilus.compute()`](/docs/api/nautilus/compute) and
[`nautilus.freeCompute()`](/docs/api/nautilus/freeCompute).

:::warning
Renamed from `ComputeAsset` in v1. ocean.js exports a *different* type under that name — the
wire-level `{ documentId, serviceId, transferTxId }` shape — and having both in scope was a
standing source of confusion. nautilus builds the ocean.js form for you from this one.
:::

## Usage

```ts twoslash
import type { ComputeAssetRef } from '@deltadao/nautilus'
// ---cut---
const dataset: ComputeAssetRef = {
  did: 'did:ope:1234abcd...'
}
```

## Properties

### did

- Type: `string`

The dataset to compute on.

### serviceId (optional)

- Type: `string`

Which service to use. Defaults to the asset's first `compute` service; an asset with no
compute service fails with a message saying so.

```ts twoslash
import type { ComputeAssetRef } from '@deltadao/nautilus'
// ---cut---
const dataset: ComputeAssetRef = {
  did: 'did:ope:1234abcd...',
  serviceId: 'ccb398c50d6abd5b456e8d7242bd856a1767a890b537c2f8c10ba8b8a10e6025' // [!code focus]
}
```

### userdata (optional)

- Type: `Record<string, unknown>`

Values for the service's consumer parameters.

```ts twoslash
import type { ComputeAssetRef } from '@deltadao/nautilus'
// ---cut---
const dataset: ComputeAssetRef = {
  did: 'did:ope:1234abcd...',
  userdata: { region: 'eu' } // [!code focus]
}
```
